Privacy Policy

Last updated: 2026-10-24

snapback is a personal backup tool used only by its owner.

What data it accesses

With the drive.file scope, snapback can only read and write the files it creates in the authorizing user's Google Drive. These are encrypted backup files. It cannot see, read or change any other files.

What data it collects

None. snapback has no server of its own. The OAuth token stays on the user's own machine, and backups go straight from the user's server to the user's Google Drive. Nothing is sent to, stored by or shared with the developer or any third party.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.

Contact

Open an issue at github.com/tod-zhang/snapback.
